# Venue Data Operations and Commercial Readiness

## Acquisition playbook
Begin with venue operators who have recurring live performances. Offer free listing and a simple weekly event update. Ask for rights to use supplied imagery and performance descriptions. Maintain explicit venue consent records.

## Operator onboarding
Verify ownership by domain email, published contact or manual admin process; collect location, hours, venue spaces, cuisine, policies, estimated spend, music programme, booking links and authorized images. Confirm update owner and cadence.

## Editorial checklist
Correct venue identity; upcoming event date/time; performance type; price estimate; seating/noise qualifiers; sources; permissions; last verification; expiry. Never promote 'live tonight' from a generic recurring description alone.

## Confidence labels
Venue confirmed / Editor verified / Visitor reported / Unverified estimate. 'Verified' requires an actual verification event and traceable source, not merely AI extraction.

## Review SLAs (proposed)
One-off event: verify within 72 hours before performance if possible. Static venue profile: recheck every 90 days. Price: recheck every 30–60 days. User flag: triage within two working days. Adjust based on capacity.

## Revenue experiments
A/B test free operator dashboard vs enhanced insights; interview venues on willingness to pay; test referral attribution before fee negotiations. No pay-to-stay listed requirement.

## Legal/compliance checklist
Content rights, API terms, trademark use, advertising disclosures, consumer transparency, data privacy, children/age policy, operator terms, complaint and takedown process, cross-border hosting assessment.
